# Real food photos

Drop your **own product photos** here to make the site look like a real
fast-food storefront. The menu is seeded to look for these filenames:

| File | Menu item |
|---|---|
| `bucket.jpg` | Original Bucket (8pc) |
| `wings.jpg`  | Hot Wings (6pc) |
| `burger.jpg` | Laka Zinger Burger |
| `fries.jpg`  | Laka Fries |
| `drink.jpg`  | Soft Drink |
| `combo.jpg`  | Laka Combo |

Recommended: square-ish JP/PNG/WebP, at least **600×600 px**. They're shown
edge-to-edge (`object-fit: cover`), so anything roughly square looks great.

## Two ways to set a photo

1. **Drop a file here** with the matching name above — it appears instantly on
   the storefront, POS and menu.
2. **Paste a link** in the staff **Menu** page (owner/manager): each item has a
   *Photo URL / path* field. Put a full `https://…` image URL (e.g. your own
   photography, or a royalty-free stock photo you're licensed to use) or a local
   path like `assets/food/photos/bucket.jpg`.

If a photo is missing or a URL fails to load, the card automatically falls back
to the built-in illustration, so nothing ever looks broken.

## Please use images you have the right to use

Use your own photos, or images under a licence that permits your use (e.g.
CC0 / public domain, or stock you've licensed). **Don't use another
restaurant's copyrighted photos** (including KFC's) — those belong to them.
