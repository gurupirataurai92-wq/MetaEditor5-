Publish to the website

Everything you have added so far lives in this browser only. These steps put it on the live site for everyone.

1

Download the catalogue file

This is your stock list, prices and company details, ready to replace the current file at website/assets/js/data.js.

2

Download the photos

Saves each photo as a file. Put them in website/assets/img/uploads/ — create that folder if it is not there. Your browser may ask permission to save several files at once; allow it.

3

Upload both to the website

Put the new data.js and the uploads folder into the site — through GitHub, your host's file manager, or whoever maintains the site for you. Once they are up, every visitor sees the new stock.

Backup

A single file holding your stock and the photos. Keep one after a big update — if this browser is cleared before you publish, it is the only way back.

Start again

Throws away everything staged in this browser and goes back to what is published on the site right now. There is no undo.

Change the password

Type a new password below. You will get a line of text to paste into assets/js/manager-config.js, replacing the PASSWORD_HASH line. The password itself is never stored anywhere.

What this sign-in does and does not do

  • It hides the manager screens from someone who wanders onto the page. That is all.
  • It cannot stop a determined person: the settings sit in a file the browser downloads, so anyone can read them.
  • Nothing here is private in any case — everything you enter is meant to be published.
  • For real accounts with genuine access control, several staff logins and an audit trail, the site needs a server back end.
